For quick checks and recording (or in case you do not have a
 MIDI device at hand), you can also use Hydrogen's
 Virtual Keyboard. It emulates note triggering via
 MIDI *NOTE_ON* events (see [MIDI Note Rendering](./02-using-hydrogen/13-midi/01-note-rendering)).
:::note
Key strokes of the Virtual Keyboard don't trigger [Actions](./02-using-hydrogen/13-midi/03-controlling) associated with
 *NOTE_ON* events.
:::

 instrument number in Input Mode `Drumkit` or instrument
 pitch in Input Mode `Instrument`.
