title: "View"
sidebar_label: "View"
---

- **Playlist Editor**: opens the [Playlist Editor](./02-using-hydrogen/12-playlist-editor) window.
- **Director**: opens the [Director](./02-using-hydrogen/11-director) window.
- **Mixer**: opens the [Mixer](./02-using-hydrogen/10-mixer/00-mixer) window.
- **Instrument Rack**: shows or hides the widget of the main window containing both the [Instrument Editor](./02-using-hydrogen/08-instrument-editor) and the [Sound Library](./02-using-hydrogen/07-sound-library).
- **Automation Path**: shows or hides the [Automation Path](./02-using-hydrogen/05-song-editor/06-automation-path) panel.
- **Timeline**: shows or hides the [Timeline](./02-using-hydrogen/05-song-editor/03-timeline) panel.
- **Playback Track**: shows or hides the [Playback Track](./02-using-hydrogen/05-song-editor/05-playback-track) panel.
- **Full screen**: maximises the window size to the whole screen area.
