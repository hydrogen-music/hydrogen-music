The Main UI comes in 2 flavors : the (classic) Single Pane mode (ideal for
 large- and medium size screens), and the Tabbed mode (optimized for netbook screen
 sizes).
:::tip
You can switch between these two modes in the [Interface](./02-using-hydrogen/02-preferences/04-appearance#chpt.preferences.appearance_tab.interface) tab of the Appearance tab in the Preferences.
:::
Below you can see the main UI split up in 5 parts: the [Main Menu](./02-using-hydrogen/03-main-menu/00-main-menu), [Main
 Toolbar](./02-using-hydrogen/04-main-toolbar/00-main-toolbar), [Song Editor](./02-using-hydrogen/05-song-editor/00-song-editor), [Pattern Editor](./02-using-hydrogen/06-pattern-editor/00-pattern-editor) and the [Instrument](./02-using-hydrogen/08-instrument-editor) and [Sound Library Editor](./02-using-hydrogen/07-sound-library).
 These sections will be explained in detail further down in this
 manual.
