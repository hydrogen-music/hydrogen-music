The Director provides a quick overview of what Hydrogen
 is currently doing. It can be opened by pressing `Alt` + `D` or by via the [View](./02-using-hydrogen/03-main-menu/04-view) option in the Main Menu.

The Director shows you the song name, a visualization of the [Metronome](./02-using-hydrogen/04-main-toolbar/02-bpm-metronome), and the
 [Tags](./02-using-hydrogen/05-song-editor/04-tags). Just below the metronome you can see the latest tag, and below that
 the next upcoming tag. This way you have a nice overview of what is going on,
 and what is about to happen in the song.
:::tip
This comes in very handy when you are [recording](./02-using-hydrogen/01-overview/03-recording) a song, or
 if you are using Hydrogen live on stage.
:::
