- **User Manual**: opens a window with a version of this manual installed on your local computer.
- **About**: the usual window with license information, acknowledgments, etc.
- **Report Bug**: opens the [Hydrogen issue page at github.com](https://github.com/hydrogen-music/hydrogen/issues) in your default Internet browser. You can open a new issue to communicate a bug here (first search if there exists already an issue about it).
- **Donate**: make a donation to developers/maintainers.
