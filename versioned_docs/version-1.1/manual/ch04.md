## 4.1. Main User Interface

> ****Figure 4.1. The Main UI in Single Pane mode****

The Main UI comes in 2 flavors : the (classic) Single Pane mode (ideal for
        large- and medium size screens), and the Tabbed mode (optimized for netbook screen 
        sizes).
        

:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip You can switch between these two modes in the [Appearance](ch05s05.html) tab of the Preferences.
:::

          Below you can see the main UI split up in 5 parts: the [Main Menu](ch06.html), [Main 
          Toolbar](ch07.html), [Song Editor](ch08.html), [Pattern Editor](ch09.html) and the [Instrument](ch11.html) and [Sound Library Editor](ch10.html).
          These sections will be explained in detail further down in this
          manual.
