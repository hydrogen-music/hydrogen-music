## 4.1. Main User Interface

![The Main UI in Single Pane mode](/img/docs/generated_en/GUI_Sections_0.9.5_v2.png)

The Main UI comes in 2 flavors: the (classic) Single Pane mode (ideal for large-
and medium size screens), and the Tabbed mode (optimized for netbook screen
sizes).
        

:::tip
You can switch between these two modes in the [Appearance](ch05s05.md) tab of the Preferences.
:::

Below you can see the main UI split up in 5 parts: the [Main Menu](ch06.md),
[Main Toolbar](ch07.md), [Song Editor](ch08.md), [Pattern Editor](ch09.md)
and the [Instrument](ch11.md) and [Sound Library Editor](ch10.md). These
sections will be explained in detail further down in this manual.
