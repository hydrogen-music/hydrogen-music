**Table 21.1. Shortcut Table**

Shortcut | Description
--- | ---
<kbd>Ctrl</kbd> + <kbd>N</kbd> | New Project
<kbd>Ctrl</kbd> + <kbd>O</kbd> | Open File
<kbd>Ctrl</kbd> + <kbd>D</kbd> | Open Demo
<kbd>Ctrl</kbd> + <kbd>S</kbd> | Save Song
<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Save Song as
<kbd>Ctrl</kbd> + <kbd>P</kbd> | Export Pattern as
<kbd>Ctrl</kbd> + <kbd>M</kbd> | Export MIDI file
<kbd>Ctrl</kbd> + <kbd>E</kbd> | Export Song (see [Export Song](ch06/ch06.md#sect.main_form.export_song))
<kbd>Ctrl</kbd> + <kbd>L</kbd> | Export LilyPond file
<kbd>Ctrl</kbd> + <kbd>Q</kbd> | Quit Hydrogen
<kbd>Ctrl</kbd> + <kbd>Z</kbd> | Undo an action
<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> | Redo an action
<kbd>Alt</kbd> + <kbd>D</kbd> | Show [Director](ch14.md)
<kbd>Alt</kbd> + <kbd>M</kbd> | Show [Mixer](ch13/ch13.md)
<kbd>Alt</kbd> + <kbd>I</kbd> | Show [Instrument Rack](ch10/ch10.md)
<kbd>Alt</kbd> + <kbd>A</kbd> | Show [Automation Path](ch08/ch08s07.md)
<kbd>Alt</kbd> + <kbd>F</kbd> | Toggle fullscreen mode
<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>I</kbd> | Set [Input mode](ch04/ch04s03.md) to Instrument
<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>D</kbd> | Set [Input mode](ch04/ch04s03.md) to Drumkit
<kbd>Alt</kbd> + <kbd>P</kbd> | Show [Preferences](ch05/ch05.md)
<kbd>Alt</kbd> + <kbd>?</kbd> | Show Manual
<kbd>Backspace</kbd> | Restart song or pattern from the beginning
<kbd>Space</kbd> | Play / Pause
<kbd>Ctrl</kbd> + <kbd>Space</kbd> | Starts playback at the current cursor position. If playback is already rolling, it will relocate to the cursor position without pausing or stopping playback. Note that on MacOS this shortcut is bound to <kbd>Alt</kbd> + <kbd>Space</kbd>.
<kbd>,</kbd> | Use the [Beat Counter](ch07/ch07s02.md#sect.main_toolbar.tap_tempo_beat_counter.beat_counter)
<kbd>\\ </kbd> | Use [Tap Tempo](ch07/ch07s02.md#sect.main_toolbar.tap_tempo_beat_counter.tap_tempo)
<kbd>+</kbd> | Increase tempo by 0.1 BPM
<kbd>-</kbd> | Decrease tempo by 0.1 BPM
<kbd>F5</kbd> | Jump to previous song in [playlist](ch15/ch15.md)
<kbd>F6</kbd> | Jump to next song in [playlist](ch15/ch15.md)
<kbd>F9</kbd> | Jump to previous bar in the song
<kbd>F10</kbd> | Jump to next bar in the song
<kbd>F12</kbd> | Panic button (stops the song and mutes all playing sounds)
