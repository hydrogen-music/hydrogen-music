- 
**Playlist Editor**: opens the [Playlist Editor](../ch15/ch15.md) window.

- 
**Director**: opens the [Director](../ch14.md) window.

- 
**Mixer**: opens the [Mixer](../ch13/ch13.md) window.

- 
**Instrument Rack**: shows or hides the widget of the main window containing both the [Instrument Editor](../ch11/ch11.md) and the [Sound Library](../ch10/ch10.md).

- 
**Automation Path**: shows or hides the [Automation Path](../ch08/ch08s07.md)
panel.

- 
**Timeline**: shows or hides the [Timeline](../ch08/ch08s04.md) panel.

- 
**Playback Track**: shows or hides the [Playback Track](../ch08/ch08s06.md) panel.

- 
**Full screen**: maximises the window size to the whole screen area.
