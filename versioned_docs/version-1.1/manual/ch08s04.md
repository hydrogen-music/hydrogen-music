8.4. Timeline
## 8.4. Timeline
![|Picture showing the Timeline above the Song Ruler.](/img/docs/generated_en/tempo_bar.png)
The majority of songs consist of several parts (intro, verse, chorus ...) and
       often these parts will have a different tempo.  Hydrogen provides an easy way
       to let you change the tempo of a song at any given moment in the song.  This is 
       done by adding *Tempo Markers* to your song.

To add a Tempo Marker you first need to show the Timeline by clicking the
       ![](/img/docs/generated_1.1/btn_viewTL_off.png)
       button at the bottom of the Song Editor or via the [View](ch06s05.html) element of the Main Menu and enable it using the
       ![](/img/docs/generated_en/btn_bpm_off.png)
       button.  Once this is done
       the horizontal bar next to the button changes to a ruler with marks at every bar.
       Now simply *left-click* this ruler at the bar you want the tempo to change and a
       window will pop up where you can enter the new tempo.
       

:::note
![[Note]](/img/docs/admonitions/note.svg) Note Please note that the ruler will not be available while using the JACK transport in *slave* mode (see [Section 7.5](ch07s05.html) for details.
:::

         
        
![](/img/docs/generated_en/add_tempo_change.png)

            
       Once you have entered the new tempo and clicked OK, the tempo change will 
       show up on the Timeline. If you click the Tempo Marker again you can edit 
       the tempo, change the bar or delete it.
