The Director provides a quick overview of what Hydrogen
is currently doing. It can be opened by pressing **Alt** + **D** or by via the [View](ch06s05.md) option in the Main Menu. 

The Director shows you the song name, a visualization of the [Metronome](ch07s03.md), and the
[Tags](ch08s05.md). Just below the metronome you can see the latest tag, and below that
the next upcoming tag. This way you have a nice overview of what is going on,
and what is about to happen in the song.


:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip This comes in very handy when you are [recording](ch04s04.md) a song, or if you are using Hydrogen live on stage.
:::
