![Figure 13.2. The Instrument Channel Strip in the Mixer](/img/docs/generated_1.1/MixerInstrumentStrip.png)

- ![|Grey button with a filled black triangle pointing to the right.](/img/docs/generated_en/btn_play_on_mixer.png) : lets you trigger the instrument at maximum velocity.

  :::tip
  This is quite handy for checking [clipping](../go01.md#def.clipping).
  :::

- ![|Vertical, grey LED-like object.](/img/docs/generated_en/led_trigger_on.png) : lights up whenever this instrument is triggered, e.g. by a note in a pattern or an external MIDI controller).
- ![|Horizontal, blue LED-like object.](/img/docs/generated_en/item_selected.png) : shows whether the instrument is currently selected (in both the Mixer and the Pattern Editor).


  :::note
  If the [Input mode](../ch06/ch06s06.md#sect.main_menu.options.input_mode) is set to Instrument , incoming MIDI events and [virtual keyboard keys](../ch04/ch04s03.md) will trigger only (pitch shifted) sounds of the currently selected instrument.
  :::


  :::tip
  An instrument can be selected by interacting with its Instrument Channel Strip in the Mixer, by interacting with its associated row in the Pattern Editor, or by the corresponding [ MIDI ](../ch16/ch16.md#chpt.midi.actions.actions.select_instrument) or [ OSC command.](../ch17/ch17s02.md#chpt.osc.command.select_instrument)
  :::


- ![](/img/docs/generated_en/btn_mute_on.png) : [mutes](../go01.md#def.mute) all sounds related to the instrument (including the preview sound you hear when clicking on the instrument name in the [Sidebar](../ch09/ch09.md#chpt.pattern_editor.sidebar) of the Pattern Editor).

  :::note
  This button is sharing its state with the mute button of corresponding instrument in the [Sidebar](../ch09/ch09.md#chpt.pattern_editor.sidebar) of the Pattern Editor.
  :::

- ![](/img/docs/generated_en/btn_solo_on.png) : solos the instrument.


  :::note
  This button is sharing its state with the solo button of corresponding instrument in the [Sidebar](../ch09/ch09.md#chpt.pattern_editor.sidebar) of the Pattern Editor.
  :::

- ![|Grey rotary widget with black background. On the widget there is a centered black circle and a black vertical line extending from the topmost point of the circle to its center.](/img/docs/generated_en/mixer_rotary.png) : sets a pan value affecting all note played using this instrument.


  :::tip
  For a detailed description of how this pan value does interact with the [note pan](../ch09/ch09s03.md#chpt.pattern_editor.note_properties.pan) and the [Pan Laws](../ch13/ch13s04.md#chpt.mixer.master_fader_strip.mixer_settings) in the Mixer please see [Pan](../go01.md#def.pan).
  :::

- ![|Grey and round widget containing a grey and centered circle as well as a short grey line to indicate the position.](/img/docs/generated_en/mixer_knob.png) : the four pre-fader FX send knobs that determine how much of this instrument will be sent to the effect plugins in the [FX Rack](../ch13/ch13s03.md).


- **Fader and LCD**: the fader next to the instrument's name allows you to adjust the volume of the instrument which will be applied on top of all the individual note velocities, layer gains etc. In the background of the fader a volume unit (VU) meter is included representing the instrument's signal level. The LCD displays shows its peak value.

  :::tip
  You can adjust the falloff speed of the peak values in the LCD display via the [Appearance](../ch05/ch05s05.md#fig.preferences.appearance_tab) tab in the Preferences.
  :::

  :::note
  If the [Create per-instrument outputs](../ch05/ch05s02.md#sect.preferences.jack.per_instrument_outs) option in the Audio Engine tab of the Preferences was selected for the JACK audio driver, Hydrogen will register ports for each instrument. All the options described above will only take effect if in addition the [Track output](../ch05/ch05s02.md#sect.preferences.jack.track_output) option in the same tab as set to Post-Fader . This allows you to route the individual instruments directly into any other JACK enabled application, like Ardour, and gives you a lot more flexibility.
  :::
