![Figure 11.2. The Instrument Editor Layers View](/img/docs/generated_en/Instrument_Layers.png)

When clicking the Layers button in the Instrument Editor you can adjust the [samples](go01.md#def.sample) and synthesizer parameters of the particular [layers](go01.md#def.layer) of the instrument selected in the [Sidebar](ch09.md#chpt.pattern_editor.sidebar) of the Pattern Editor.


### 11.2.1. Components
![|In the center you can find the name of the Drumkit component and at the right end a button to open a context menu.](/img/docs/generated_1.1/InstrumentEditorLayersComponents.png)

Right below the General and Layers button you find the name of the currently selected [component](go01.md#def.component). In the drop down menu accessible by pressing
![|Grey button with a black filled triangle pointing downwards.](/img/docs/generated_1.1/btn_dropdown_off.png)
you find a list of all components available in the current drumkit and can select them via a *left click*. Below a separator you can also find three options to add a new component, delete the current one, or rename the current one.


:::warning
![[Warning]](/img/docs/admonitions/warning.svg) Warning The components are shared by all instruments. This means deleting it will delete it including all associated layers from a *all* instruments and not just the currently selected one.
:::

### 11.2.2. Layers

![Figure 11.3. The Layer Section of the Instrument Editor](/img/docs/generated_1.1/InstrumentEditorLayersLayers.png)

Next you find a listing of all layers of the current component in the selected instrument. The wave form of the sample loaded to the currently selected layer (the one enclosed by a red rectangle) is displayed below.


:::note
![[Note]](/img/docs/admonitions/note.svg) Note Empty layers will be displayed as < - > .
:::

Using
![](/img/docs/generated_en/loadLayer_off.png)
you can load a sample into the currently selected layer, using
![](/img/docs/generated_en/deleteLayer_off.png)
you can delete the current layer, and using
![](/img/docs/generated_en/editLayer_off.png)
you can open the [Sample Editor](ch12.md) to customize the sample loaded to the currently selected layer.


:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip Alternatively you can also *double-click* the wave display to open the [Sample Editor](ch12.md).
:::

:::note
![[Note]](/img/docs/admonitions/note.svg) Note When loading a sample it will per-default have its active area set to the whole velocity range. By checking the **Set auto velocity** option all layers will be assigned an equally sized velocity range corresponding to their layer number (the top-most layer will have a range starting a zero velocity and the bottom-most one that ends at maximum velocity). Note however that this option will overwrite all existing velocity ranges.
:::

Above the layer listing you find boxes in different shades of grey indicating which range of note [velocity](go01.md#def.velocity) will trigger which sample (left: 0 velocity, right: maximum velocity). *Left-clicking* on any of these boxes will play back the sound of associated sample modulated by the velocity corresponding to the horizontal position of the mouse cursor.


:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip This will be quite handy when adjusting the velocity ranges of the layers.
:::


You might have already noticed in the picture above or for shipped drumkits in the Hydrogen GUI that a layer row contains a light blue rectangle that those not quite fill the whole row. This rectangle indicates the range in velocity the associated sample should be triggered. This way you can separate samples for soft hits, regular hits, and so on for each instrument (component). Whenever two rectangles do overlap a triggered note with a velocity within this shared range will consult the [Sample Selection](ch11s02.md#chpt.instrument_editor.layers.sample_selection) to determine which sample will be played back. You can adjust the velocity ranges of each layer by *left-clicking* the left or right end of the light blue rectangles and *dragging* it to the desired position.


:::note
![[Note]](/img/docs/admonitions/note.svg) Note If there is a(n accidental) hole between two adjacent velocity ranges, the layer closest to the triggered velocity will be used.
:::

### 11.2.3. Sample Selection
![](/img/docs/generated_1.1/InstrumentEditorLayersSampleSelection.png)

Having a set of samples containing different sample versions of similar sound for the same note velocity is a good way to make your drumkit sound more natural. After all, drummers for example never hit the drum set twice the exact same way.


Hydrogen tries to emulate this behavior by providing multiple [layers](ch11s02.md#chpt.instrument_editor.layers.layers) with overlapping velocity ranges. *How* the selection of the resulting sample will take place is for you to decide using the **Sample Sel.** dropdown menu at the bottom of the Instrument Editor.


- 
First in Velocity:
will select the first sample available in the velocity set - the one of the layer most further down in the layer listing.


:::note
![[Note]](/img/docs/admonitions/note.svg) Note This is the way previous versions of Hydrogen were working.
:::


- 
Round Robin:
will cycle through the different samples one after another as note a in the same velocity range are played.


- 
Random:
will select a random sample inside the velocity range for each note played.


### 11.2.4. Controls
![](/img/docs/generated_1.1/InstrumentEditorLayersControls.png)
- 

**Layer Gain**:
adds [Gain](go01.md#def.gain) for the currently selected layer and the associated sample.


- 

**Component Volume**:
adjusts the volume of all layers within the current component with respect to the ones of the other instruments.


:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip The resulting audio from all layers of each instrument associated with a certain component can be controlled via its [Component Channel Strip](ch13s02.md) in the Mixer.
:::


- 

**Pitch**:
adjusts the pitch of the currently selected layer and the associated sample in quantized steps of half-tones from -24 to +24.


- 

**Fine**:
adjusts the pitch of the currently selected layer and the associated sample in quantized steps of cents of half-tones from -0.50 to +0.50.
