18.4. Adjust from the Mixer
## 18.4. Adjust from the Mixer

Of course we can always use the [Mixer](ch13.md) window, either when creating
       or playing patterns.

The Mixer (see [Figure 18.3](ch18s04.md#fig.mixer.2)) is made of a number
       independent [Instrument Channel Strips](ch13.md#chpt.mixer.channel_strips), each of these is bound to an instrument, plus a
       [Master Fader Strip](ch13s04.md) and a 
        ![](/img/docs/generated_1.1/showFX_on.png)
          button to show and hide the 
       [FX Plugin Rack](ch13s03.md).
       Every line features 3 buttons (

       ![|Grey button with a filled black triangle pointing to the right.](/img/docs/generated_en/btn_play_on_mixer.png)

       ![](/img/docs/generated_en/btn_solo_on.png)

       ![](/img/docs/generated_en/btn_mute_on.png)

       ), current maximum peak, FX volume control knobs, volume fader, and name of the track. Clicking on

       ![](/img/docs/generated_en/btn_solo_on.png)

       will play the selected instrument, cutting the others. The Mute button

       ![](/img/docs/generated_en/btn_mute_on.png)

       , simply [mute](go01.md#def.mute) *that* instrument. The maximum peak
       indicates the maximum volume reached from the instrument.   The peak must
       be in a range of 0.0 and 1.0 (in [Figure 18.3](ch18s04.md#fig.mixer.2) you can
       see a few volumes too loud). For a full description of the Mixer and its elements please see [Mixer](ch13.md).

       

:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip Peaks outside that range will get distorted (especially with OSS audio driver). Keep an eye on each VU meter and if distortion appears, turn the volume down for that instrument.
:::
