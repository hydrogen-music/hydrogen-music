The Instrument Editor is located in the Instrument Rack in the lower right corner of Hydrogen, which can be shown or hidden via the [View](../ch06/ch06s05.md) option in the Main Menu or via the [corresponding button](../ch07/ch07s06.md) in the Main Toolbar. The Instrument Rack does either show the [Instrument Editor](../ch11/ch11.md) or the Sound Library depending on what is chosen in the [View](../ch06/ch06s05.md) option in the Main Menu or the corresponding buttons at the top of the Instrument Rack.
