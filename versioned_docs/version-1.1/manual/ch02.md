:::tip
The instructions provided in this section are for Linux only. If you intend to build Hydrogen on macOS, check out the corresponding [wiki page](https://github.com/hydrogen-music/hydrogen/wiki/Building-Hydrogen-from-Source-(macOS)) for tips or guides.
:::

If you want to compile Hydrogen yourself, you can download the latest source files directly from our
git repository with

``` bash
git clone git://github.com/hydrogen-music/hydrogen.git
```

A certain release can be fetched with

```bash
git checkout tags/1.0.0
```

Compiling Hydrogen depends on the following libraries (among others):

- **Qt 5**: at [http://www.qt.io](http://www.qt.io)

- **libsndfile**: at [http://www.mega-nerd.com/libsndfile/](http://www.mega-nerd.com/libsndfile/)

- **ALSA**: (>= 1.x) at [http://www.alsa-project.org](http://www.alsa-project.org)
(only if you wish to use ALSA as audio driver)

- **Jack Audio Connection Kit (>= 0.80)**: at 
[http://jackaudio.org/](http://jackaudio.org/)
(only if you wish to use JACK as audio driver)

- **PortAudio**: at [http://www.portaudio.com](http://www.portaudio.com)
(only if you wish to use PortAudio as audio driver)

- **PulseAudio**: at [http://www.pulseaudio.org](http://www.pulseaudio.org)
(only if you wish to use PulseAudio as audio driver)

- **Flac**: at [http://flac.sf.net](http://flac.sf.net) (only if you
wish to use Flac samples)

- **LADSPA**: at [http://www.ladspa.org](http://www.ladspa.org) (only if you wish
to use LADSPA effects)

- **liblrdf**: at [http://sf.net/projects/lrdf](http://sf.net/projects/lrdf) (only if you wish to use lrdf to categorise effects)

- **LASH**: at [http://lash.nongnu.org](http://lash.nongnu.org) (only if
you wish to use LASH)

- **liblo**: at [http://liblo.sourceforge.net/](http://liblo.sourceforge.net/) for [OSC](ch17/ch17.md) and [NSM](ch04/ch04s05.md#chpt.overview.session_management.nsm) support


Please install them with your distribution's package manager. If
you're running a Debian-based system, you can install the libraries
with:

```bash
apt-get install qtbase5-dev qtbase5-dev-tools               \
    qttools5-dev qttools5-dev-tools libqt5xmlpatterns5-dev  \
    libarchive-dev libsndfile1-dev libasound2-dev liblo-dev \
    libpulse-dev libcppunit-dev liblrdf-dev                 \
    liblash-compat-dev librubberband-dev libjack-jackd2-dev
```

Compiling with `cmake` can be done easily by using the build.sh script. Go to the directory where the git repository
was cloned and run the build.sh script without any arguments to display the help :

```bash
./build.sh
```

The help is now displayed:

```
r[m]     => all built, temp and cache files
c[lean]  => remove cache files
m[ake]   => launch the build process
mm       => launch the build process using ccache
mt       => launch the build process with clang tidy checks enabled
d[oc]    => build html documentation
g[raph]  => draw a dependencies graph
h[elp]   => show the build options
x|exec   => execute hydrogen
t[ests]  => execute tests
p[kg]    => build source package
z        => build using ccache and run from tree
```

To build Hydrogen and execute the result, run the build script with the `m` option

```bash
./build.sh m x
```

and to install it permanently on your computer, change into the build folder and use the `make` command.


```bash
cd build
sudo make install
```

:::note
For further details about the installation process please have a look the INSTALL.txt file (located in the top level directory once you downloaded the sources).
:::
