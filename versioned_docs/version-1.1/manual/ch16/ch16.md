In this section you can find more info about how to make Hydrogen respond to MIDI messages. This is either done using the [available MIDI Actions](#chpt.midi.actions) or using the [MIDI-learnable Widgets](../ch16/ch16s02.md), like knobs or faders, both triggered using [MIDI Events](#chpt.midi.actions).


:::note
![[Note]](/img/docs/admonitions/note.svg) Note Before you can work with MIDI actions you should have your MIDI devices, drivers, and connections configured correctly in the [MIDI System ](../ch05/ch05s03.md) tab of the Preferences. Please note that this chapter will only cover the table linking external MIDI Events to Hydrogen's MIDI Actions. For all other parameters of the MIDI API please see the [MIDI System ](../ch05/ch05s03.md) tab of the Preferences.
:::
