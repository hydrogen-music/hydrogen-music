6.5. View
## 6.5. View

- 
**Playlist Editor**: opens the [Playlist Editor](ch15.html) window.

- 
**Director**: opens the [Director](ch14.html) window.

- 
**Mixer**: opens the [Mixer](ch13.html) window.

- 
**Instrument Rack**: shows or hides the widget of the main window containing both the [Instrument Editor](ch11.html) and the [Sound Library](ch10.html).

- 
**Automation Path**: shows or hides the [Automation Path](ch08s07.html)
            panel.

- 
**Timeline**: shows or hides the [Timeline](ch08s04.html) panel.

- 
**Playback Track**: shows or hides the [Playback Track](ch08s06.html) panel.

- 
**Full screen**: maximises the window size to the whole screen area.
