7.4. CPU Usage and MIDI in
## 7.4. CPU Usage and MIDI in
![](/img/docs/generated_1.1/MidiIN_CPU.png)
The CPU bargraph gives you an indication of the CPU load. The MIDI led lights up every time Hydrogen receives a MIDI message.

:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip The MIDI settings can be adjusted in the [MIDI tab](ch05s03.html) of the Preferences.
:::
