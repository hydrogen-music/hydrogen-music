## Chapter 16. MIDI API

In this section you can find more info about how to make Hydrogen respond to MIDI messages. This is either done using the [available MIDI Actions](ch16.md#chpt.midi.actions) or using the [MIDI-learnable Widgets](ch16s02.md), like knobs or faders, both triggered using [MIDI Events](ch16.md#chpt.midi.actions).

![[Note]](/img/docs/admonitions/note.svg) Note Before you can work with MIDI actions you should have your MIDI devices, drivers, and connections configured correctly in the [MIDI System ](ch05s03.md) tab of the Preferences. Please note that this chapter will only cover the table linking external MIDI Events to Hydrogen's MIDI Actions. For all other parameters of the MIDI API please see the [MIDI System ](ch05s03.md) tab of the Preferences.
:::

## 16.1. MIDI Actions

![Figure 16.1. MIDI Actions are set in MIDI System tab of the Preferences Dialog](/img/docs/generated_en/MidiSystem_V2.png)

An MIDI **Event** is an incoming MIDI message, originating from e.g. a MIDI controller or an external sequencer. A MIDI **Action** is a function built into Hydrogen that can be used to react to a specific MIDI Event. Binding an Event to an Action can be done using the [MIDI System](ch05s03.md) tab of the Preferences.
      

	    You can also define MIDI bindings by simply pressing the
        ![|Red circle.](/img/docs/generated_1.1/rec.png)
        button left of the Event-Action binding line. 
        A popup will inform you that Hydrogen is waiting for your input.  Press/hit/turn 
        the key/pad/knob on your MIDI keyboard (or controller) that you want to link to 
        this action.  The popup will close and the **Event Param.** value will now show the 
        MIDI note value of the key you pressed.  Once this is done you can select an Action 
        from the action drop-down list.
      

:::tip
![[Tip]](/img/docs/admonitions/tip.svg) Tip You can also define a binding without the ![|Red circle.](/img/docs/generated_1.1/rec.png) button by setting the **Event Param.** manually to the desired MIDI note.
:::

        The **Action Param.** column to the right of the table specifies the input parameter to the Action (see the corresponding [Actions reference](ch16.md#chpt.midi.actions.actions) for details).
      

### 16.1.1. Events

            Three types of MIDI Events are available (as described in the MIDI standard):
          

- 

	          **NOTE**: an input coming from a regular black/white key of a keyboard or a drumpad.
	        

- 

	          **CC**: controller commands coming from faders or rotary controllers.
	        

- 

	          **MMC_x**: [
	          machine control events](http://en.wikipedia.org/wiki/MIDI_Machine_Control) coming from buttons, like 'play' or 'stop',  on a controller.
	        

### 16.1.2. Actions

:::note
![[Note]](/img/docs/admonitions/note.svg) Note Some of the MIDI Actions require that the **Action Param.** is configured. This parameter usually references a specific channel, instrument, FXsend... Keep in mind that its value is *zero-based* . So, if you want to reference channel 1 you have to enter 0 in the **Action Param.** field ( 1 for channel 2, 2 for channel 3, and so on).
:::

- 

	           **&lt;&lt;_PREVIOUS_BAR**:
               moves the playhead to the previous pattern/bar.
             

- 

	           **>>_NEXT_BAR**:
               moves the playhead to the next pattern/bar.
             

- 

	         **BEATCOUNTER**: calculates the average
             time passing between successive encounters of this commands and uses
             it to set the current tempo using the [Beat Counter](ch07s02.md#sect.main_toolbar.tap_tempo_beat_counter.beat_counter).
	       

- 

	           **BPM_CC_RELATIVE**: changes the tempo relative to the current tempo, using a controller. Using the **Action Param** you can specify by how much the current tempo will change. If the incoming Event is -1 (negative), the tempo will be increased and if it's 1 (positive), it will be increased.
               

:::note
![[Note]](/img/docs/admonitions/note.svg) Note This Action will have no effect if Hydrogen is both in [Song mode](ch08s02.md#chpt.song_editor.editor_modes.song_mode) and the [Timeline](ch08s04.md) is activated.
:::

	         

- 

	         **BPM_DECR**: decreases the current tempo
             by the supplied value.
           

:::note
![[Note]](/img/docs/admonitions/note.svg) Note This Action will have no effect if Hydrogen is in [Song mode](ch08s02.md#chpt.song_editor.editor_modes.song_mode) or [Timeline](ch08s04.md) is activated.
:::

- 

	           **BPM_FINE_CC_RELATIVE**:
               as [BPM_CC_RELATIVE](ch16.md#chpt.midi.actions.actions.bpm_cc_relative) but with changes 100 times smaller than the value specified in **Action Param**.
               

:::note
![[Note]](/img/docs/admonitions/note.svg) Note This Action will have no effect if Hydrogen is in [Song mode](ch08s02.md#chpt.song_editor.editor_modes.song_mode) or [Timeline](ch08s04.md) is activated.
:::

             

- 

	         **BPM_INCR**: increases the current tempo
             by the supplied value.
           

:::note
![[Note]](/img/docs/admonitions/note.svg) Note This Action will have no effect if Hydrogen is in [Song mode](ch08s02.md#chpt.song_editor.editor_modes.song_mode) or [Timeline](ch08s04.md) is activated.
:::

- 

             **EFFECTx_LEVEL_ABSOLUTE**:
                          changes the [volume level of an FX](ch13.md#chpt.mixer.channel_strips.fx_volume) x provided as an integer between 0 and 127. The value you enter in the **Action Param** determines the [Instrument Channel Strip](ch13.md#chpt.mixer.channel_strips) the Action will be applied to.
           

- 

             **EFFECTx_LEVEL_RELATIVE**:
             

:::warning
![[Warning]](/img/docs/admonitions/warning.svg) Warning Not implemented yet.
:::

           

- 

	           **FILTER_CUTOFF_LEVEL_ABSOLUTE**:
               for a value of 0 it sets the [Filter Cutoff](ch11.md#chpt.instrument_editor.filter) of the
                 instrument strip specified using the **Action Param** to 0. For all other
                 values it sets the cutoff to the provided number divided by
                 127.0.
             

- 

	         **MASTER_VOLUME_ABSOLUTE**: sets the [Master output volume](ch13s04.md) to the value provided by the MIDI event times 1.5 and divided by 127.
	       

- 

	         **MASTER_VOLUME_RELATIVE**: changes the [Master output volume](ch13s04.md), relative
	         to its current setting. For a value of 0 it sets the volume of
             the master fader to 0. For a value of 1 it increases its
             volume by 0.05 and for all other values it decreases it by
             0.05. (-1: -0.05 , 0: 0 ,1: +0.05)
	       

- 

             **MUTE**: [mutes](go01.md#def.mute) the [Master output](ch13s04.md) (sequencer keeps running).
	       

- 

	         **MUTE_TOGGLE**: toggles the [muting](go01.md#def.mute) of the
             [Master output](ch13s04.md) (sequencer keeps running).
	       

- 

	         **PAN_ABSOLUTE**: changes the [pan](go01.md#def.pan) of an [instrument](ch13.md#chpt.mixer.channel_strips.pan) determined by the **Action Param** to the absolute value - from 0 to 127 - that the linked controller sends to Hydrogen.
	       

- 

	         **PAN_RELATIVE**: changes the [pan](go01.md#def.pan) of an [instrument](ch13.md#chpt.mixer.channel_strips.pan) determined by the **Action Param** relative to the current value. For a
             value of 1 it increase the pan by 0.05. For all other values
             it decreases it by 0.05. (-1: -0.05 , 1: +0.05).
	       

- 

	         **PAUSE**: pauses playback.
	       

- 

	         **PLAY**: starts playback.
	       

- 

	         **PLAY/PAUSE_TOGGLE**: works the same as
             [PLAY](ch16.md#chpt.midi.actions.actions.play) if the
             playback has not started yet and same as. 
             [PAUSE](ch16.md#chpt.midi.actions.actions.pause) otherwise. (The playhead will not return
	         to the start of the song, but will stay at its current position).
	       

- 

             **PLAY/STOP_TOGGLE**: works the same as [PLAY](ch16.md#chpt.midi.actions.actions.play) if the
             playback has not started yet and same as.
             [STOP](ch16.md#chpt.midi.actions.actions.stop) otherwise.
	       

- 

	           **PLAYLIST_NEXT_SONG**:
               opens the song in the current [playlist](ch15.md) corresponding to the song number specified in **Action Param**.
             

- 

	           **PLAYLIST_PREV_SONG**:
               opens the previous song in the current [playlist](ch15.md).
             

- 

	           **PLAYLIST_SONG**:
               opens the next song in the current [playlist](ch15.md).
             

- 

	           **RECORD/STROBE_TOGGLE**:
               toggles [recording](ch04s04.md) (same as pressing the [record button](ch07.md#sect.main_toolbar.transport_control)
                 in the main toolbar).
             

- 

	           **RECORD_EXIT**:
               deactivates [recording](ch04s04.md).
             

- 

	           **RECORD_READY**:
               toggles [recording](ch04s04.md) (same as pressing the [record button](ch07.md#sect.main_toolbar.transport_control)
                 in the main toolbar) if the playback has not started yet.
             

- 

	           **RECORD_STROBE**:
               activates [recording](ch04s04.md).
             

- 

	           **REDO_ACTION**:
               redoes the previous undone action.
             

- 

             **SELECT_AND_PLAY_PATTERN**: works as
             [SELECT_NEXT_PATTERN](ch16.md#chpt.midi.actions.actions.select_next_pattern) combined with
             [PLAY](ch16.md#chpt.midi.actions.actions.play).
	       

- 

	           **SELECT_INSTRUMENT**:
               selects the instrument in the drumkit corresponding to the number supplied in the incoming MIDI Event.
	       

- 

             **SELECT_NEXT_PATTERN**:
             switches to the pattern specified in **Action Param**.

             

:::note
![[Note]](/img/docs/admonitions/note.svg) Note If Hydrogen is in [Song mode](ch08s02.md#chpt.song_editor.editor_modes.song_mode), the command will have no effect.
:::

           

- 

             **SELECT_NEXT_PATTERN_CC_ABSOLUTE**:
             like [SELECT_NEXT_PATTERN](ch16.md#chpt.midi.actions.actions.select_next_pattern) but only take effect in [Stacked mode](ch08s02.md#chpt.song_editor.editor_modes.stacked).
           

- 

             **SELECT_NEXT_PATTERN_RELATIVE**:
             switches **Action Param** patterns forward.

             

:::note
![[Note]](/img/docs/admonitions/note.svg) Note This Action does only increment the pattern number and will only take effect if Hydrogen is in [Stacked mode](ch08s02.md#chpt.song_editor.editor_modes.stacked).
:::

           

- 

             **SELECT_ONLY_NEXT_PATTERN**:
             clears the list of patterns scheduled to be played next and adds the one specified in **Action Param**.
             

:::note
![[Note]](/img/docs/admonitions/note.svg) Note If either [Song mode](ch08s02.md#chpt.song_editor.editor_modes.song_mode) or [Stacked mode](ch08s02.md#chpt.song_editor.editor_modes.stacked) is activated, this action will have no effect.
:::

           

- 

	         **STOP**: stops playback and moves the
             playhead to the beginning of the song.
	       

- 

	         **STRIP_MUTE_TOGGLE**:
             [mutes](go01.md#def.mute) the instrument specified in **Action Param**.
	       

- 

	         **STRIP_SOLO_TOGGLE**:
             [mutes](go01.md#def.mute) the instrument specified in **Action Param**.
	       

- 

	         **STRIP_VOLUME_ABSOLUTE**: see  [MASTER_VOLUME_ABSOLUTE](ch16.md#chpt.midi.actions.actions.master_volume_absolute), but applies to
	         the [Instrument Channel Strip](ch13.md#chpt.mixer.channel_strips) specified in **Action Param**.
	       

- 

	         **STRIP_VOLUME_RELATIVE**: see [MASTER_VOLUME_RELATIVE](ch16.md#chpt.midi.actions.actions.master_volume_relative), but applies to
	         the [Instrument Channel Strip](ch13.md#chpt.mixer.channel_strips) specified in **Action Param**.
	       

- 

	         **TAP_TEMPO**: another command
             calculating the average time passing between successive encounters of
             this commands and uses it to set the current tempo using [Tap Tempo](ch07s02.md#sect.main_toolbar.tap_tempo_beat_counter.tap_tempo).
	       

- 

	         **TOGGLE_METRONOME**:
             toggles the metronome.
	       

- 

	         **UNDO_ACTION**:
             undoes the previous action.
	       

- 

	         **UNMUTE**: unmutes the [Master output](ch13s04.md) (sequencer keeps running).
