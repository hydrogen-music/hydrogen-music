The Song Editor has two different *interaction modes*. The
default [**Select mode**](../ch08/ch08s02.md#chpt.song_editor.editor_modes.select) allows
pattern blocks to be set, cleared, selected, moved and
copied. The [**Draw mode**](../ch08/ch08s02.md#chpt.song_editor.editor_modes.draw)
instead allows pattern sequences to be drawn freehand.


In both modes, you can perform basic editing: clicking an
empty square activates the pattern in that time slot, and
clicking again will deactivate it.


They keyboard can also be used for editing. The arrow keys
<kbd>↑</kbd>|<kbd>↓</kbd>|<kbd>←</kbd>|<kbd>→</kbd>
will move the keyboard input cursor, and pressing
<kbd>Return</kbd> will activate or deactivate the
pattern in the current column.


In addition, there are two major *playback modes*, [**Song mode**](../ch08/ch08s02.md#chpt.song_editor.editor_modes.song_mode) and [**Pattern mode**](../ch08/ch08s02.md#chpt.song_editor.editor_modes.pattern_mode), with two minor submodes, **Single Pattern mode** (covered in the [Pattern mode](../ch08/ch08s02.md#chpt.song_editor.editor_modes.pattern_mode) section), and [**Stacked mode**](../ch08/ch08s02.md#chpt.song_editor.editor_modes.stacked). These will determine which parts of the song you will listen too during playback.


:::note
While Select mode, Draw mode, Single Pattern mode, and Stacked mode are activated via the [Main Controls](../ch08/ch08.md#chpt.song_editor.main_controls) of the Song Editor, Song mode and Pattern mode are activated via the [Transport Control](../ch07/ch07.md#sect.main_toolbar.transport_control) section of the Main Toolbar.
:::

### 8.2.1. Select Mode

This mode allows
you to select multiple patterns in the Song Editor and
delete/move/copy them.


Once you have selected a part of your song you can
**delete** it by pressing
<kbd>Delete</kbd>.  You can **move** it by simply *dragging* your
selection to another location with your mouse, or by
cutting (<kbd>Ctrl</kbd> + <kbd>x</kbd>) and
pasting (<kbd>Ctrl</kbd> + <kbd>v</kbd>) using
your keyboard. You can also **copy** your selection by either
holding <kbd>Ctrl</kbd> while *dragging* it to a new
location, or by copying (<kbd>Ctrl</kbd> +
<kbd>c</kbd>) and pasting (<kbd>Ctrl</kbd> +
<kbd>v</kbd>) using your keyboard.


Selections can be modified by holding <kbd>Ctrl</kbd> while clicking to select
additional blocks, or to remove selected blocks from the
selection.


The arrow keys on the keyboard can also be used, along
with <kbd>Return</kbd>, to **select**, **move** and **copy** parts of the
song:


- <kbd>Shift</kbd> + <kbd>↑</kbd>|<kbd>↓</kbd>|<kbd>←</kbd>|<kbd>→</kbd> can be used to make selections using the keyboard
- <kbd>Return</kbd> over a selected block will begin a move or copy
- <kbd>↑</kbd>|<kbd>↓</kbd>|<kbd>←</kbd>|<kbd>→</kbd> to move the selected cells into position
- <kbd>Return</kbd> to move the selected blocks into place
- <kbd>Ctrl</kbd> + <kbd>Return</kbd> to **copy** the selected blocks into place

Pressing <kbd>Esc</kbd> will cancel an editing operation that's in
progress, or clear any selection.


### 8.2.2. Draw Mode

This mode allows you to insert patterns by drawing -
holding the left button while moving the mouse - blocks on
the song canvas.


Clicking a square on the song canvas will add a pattern
(the square will turn blue) and clicking it again will
remove it. Holding the mouse button down will continue
either adding or removing patterns from under the mouse
cursor.


Using the arrow keys on the keyboard, and the <kbd>Return</kbd>,
will also add and remove patterns from the song.


:::note
The keyboard input cursor is usually hidden unless you press one of the keys listed in [Chapter 3](../ch03.md). You can alter this default behavior in the [General tab](../ch05/ch05.md#chpt.preferences.general_tab) of the Preferences.
:::

### 8.2.3. Song Mode

When *Song mode* is selected Hydrogen will play the sequence of patterns you have created in the Song Editor from left to right until it reaches the end of the song.


:::tip
By enabling [Loop mode](../ch07/ch07.md#sect.main_toolbar.transport_control) in the transport control, the playback will move seamlessly to the beginning again after reaching the end of the song.
:::

### 8.2.4. Pattern Mode

When *Pattern mode* is selected 
Hydrogen will play the pattern that is currently selected in the Song Editor and displayed 
in the [Pattern Editor](../ch09/ch09.md). This usual behavior is also called *Single Pattern mode*.


:::tip
By enabling [Loop mode](../ch07/ch07.md#sect.main_toolbar.transport_control) in the transport control, the playback will move seamlessly to the beginning again after reaching the end of the pattern.
:::

### 8.2.5. Stacked Mode

Normally when composing a pattern and editing it, you'll
listen to that single pattern looping over and over again
while working on it. Sometimes, however, it's useful to
hear that pattern in the context of other patterns (for
example, other instrument parts) while working on it.


Stacked mode will play multiple patterns simultaneously,
on a loop. You can select which patterns play using
<kbd>Ctrl</kbd> + *left click* on the
pattern's name. Selected patterns are all marked with a
triangle.


:::note
Hydrogen's playback mode must be set to **Pattern** rather than **Song** for Stacked mode to take effect.
:::
