![](/img/docs/generated_en/bg_topPanel.png)

- ![](/img/docs/generated_en/btn_clear_off.png) : deletes all patterns (asks for confirmation!).
- ![|Grey button containing a plus sign.](/img/docs/generated_en/btn_new_on.png) : creates a new pattern (and asks for a name).
- ![|Two grey button horizontally aligned. The left contains a black arrow tip pointing downwards and the right one one pointing upwards.](/img/docs/generated_en/btn_updown.png) : moves currently selected pattern up or down.

  :::tip
  You can also *drag-and-drop* a pattern up/down in the pattern list.
  :::

- ![|Grey button containing a black brush.](/img/docs/generated_en/btn_draw.png) : enables Select mode ([Section 8.2.1](../ch08/ch08s02.md#chpt.song_editor.editor_modes.select)).
- ![|Blue button containing four black horizontal dots in the lower part joined by three black vertical dots at the right bottom corner.](/img/docs/generated_en/btn_select.png) : enables Draw mode ([Section 8.2.1](../ch08/ch08s02.md#chpt.song_editor.editor_modes.select)).
- ![|Grey button with a horizontal black line.](/img/docs/generated_en/btn_pattern_mode.png) : sets Hydrogen to *Single Pattern mode* ![|Grey button with three horizontal black lines stacked vertically.](/img/docs/generated_en/btn_stacked_mode.png) or to *Stacked mode* ([Section 8.2.5](../ch08/ch08s02.md#chpt.song_editor.editor_modes.stacked)).
