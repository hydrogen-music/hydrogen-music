## Installer

### Linux

Versione stabile corrente:

* [Hydrogen 1.2.6 AppImage](https://github.com/hydrogen-music/hydrogen/releases/download/1.2.6/Hydrogen-1.2.6-x86_64.AppImage)

Inoltre, puoi verificare se una versione recente è disponibile nei repository
della tua distribuzione (vedi
[Repology](https://repology.org/project/hydrogen-drum-machine/versions)
per una lista compilata). Se non ne trovi una per la tua distribuzione, chiedi
ai maintainer della tua distribuzione di includere Hydrogen.

Versioni precedenti:

## Sorgenti

Il codice sorgente di Hydrogen per la release più recente può essere scaricato da GitHub:

```bash
git clone -b releases/1.2 git://github.com/hydrogen-music/hydrogen.git
```

Per maggiori informazioni sulla compilazione di Hydrogen dai sorgenti, vedi la nostra [guida alla compilazione per Linux](https://github.com/hydrogen-music/hydrogen/wiki/Building-Hydrogen-from-Source).
