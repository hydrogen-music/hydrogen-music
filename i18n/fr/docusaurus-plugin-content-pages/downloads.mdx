## Installateurs

### Linux

Version stable actuelle :

* [Hydrogen 1.2.6 AppImage](https://github.com/hydrogen-music/hydrogen/releases/download/1.2.6/Hydrogen-1.2.6-x86_64.AppImage)

Vous pouvez également vérifier si une version récente est disponible dans les dépôts de votre distribution (voir [Repology](https://repology.org/project/hydrogen-drum-machine/versions) pour une liste compilée). Si vous n'en trouvez pas pour la vôtre, demandez aux mainteneurs de votre distribution d'inclure Hydrogen.

## Sources

Le code source d'Hydrogen pour la version la plus récente peut être récupéré via GitHub :

```bash
git clone -b releases/1.2 git://github.com/hydrogen-music/hydrogen.git
```

Pour plus d'informations sur la compilation d'Hydrogen depuis les sources, consultez notre [guide de compilation Linux](https://github.com/hydrogen-music/hydrogen/wiki/Building-Hydrogen-from-Source).
