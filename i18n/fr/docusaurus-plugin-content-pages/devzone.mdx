Hydrogen est un projet open source développé collectivement par de nombreuses personnes à travers le monde.

Si vous souhaitez participer à ce projet, consultez notre [page de contribution](/contribution) pour voir comment vous pouvez vous impliquer.

Le code source d'Hydrogen ainsi que notre suivi des problèmes sont hébergés sur [GitHub](https://github.com/hydrogen-music/hydrogen).

Si vous avez des questions sur le développement d'Hydrogen ou si vous souhaitez simplement communiquer avec les développeurs d'Hydrogen, vous pouvez nous contacter via notre [liste de diffusion de développement](http://lists.sourceforge.net/mailman/listinfo/hydrogen-devel).
